# GPUPVS 阶段性变更记录

本文档记录当前插件已经完成的阶段性整理与修复结果，便于后续回顾“现在已经做到哪一步”。

## 已完成

### 1. 主链路闭环打通

- 已实现 `Collect -> Setup -> Compute -> WriteBack`
- 已支持将构建结果保存为 `SceneData` 资产
- 已支持编辑器内加载、可视化、剔除和摘要诊断

### 2. 关键稳定性问题修复

- 修复过可见性全可见问题
- 修复过 `FGPUPVSBox3f` 对齐问题引发的异常读取风险
- 修复过极端高度炸飞问题，并明确小三角形过滤阈值要求
- 修复过天空盒几何误入 Setup 的问题
- 修复过日志类别导出导致的编辑器链接错误

### 3. Editor 界面整理

- 参数已按 `基础 / Setup / Compute / 输出 / 调试` 分组
- 面板已收成卡片式布局
- 状态条已显示关卡、`Cells`、`SceneData`、可视化、剔除和线框状态
- 关键按钮已有状态高亮与明确日志

### 4. 模块职责收口

- `Editor` 负责视口位置获取与面板交互
- `Runtime` 负责 PVS 构建、加载和消费逻辑
- `SceneData` 资产保存职责已迁移到 `Editor`

### 5. 代码精简

- 删除了废弃的 `SimpleComputeShader` 样例链路
- 删除了旧的单阶段 `Visibility` 路径
- 删除了无效字段 `SceneNormals`、`TriangleBounds`、`VisibilityRayCount`
- 收口了 `Editor` 按钮 handler、状态色逻辑和设置同步逻辑
- 为 Consumer 增加了解析缓存，降低了重复全局扫描

## 当前状态总结

可以把当前阶段理解为：

- 算法主链路已可用
- 工具闭环已形成
- 结构已经从“调试工程”收敛到“可交付插件”
- 但核心性能与部分结果质量问题仍待后续专项优化

## 下一阶段重点

后续如果继续投入，优先级建议为：

1. `Compute` 成本和 GPU crash 风险
2. `Setup` 语义与参考工程的系统对齐
3. 大范围构建时的工作量保护和分批策略
